MHAC DELIVERY ADMIN APP

Purpose:
- Android wrapper for the locked MHAC Admin web app.
- Opens the existing Admin URL directly inside the app.
- Uses the MHAC logo as the app icon.
- Does NOT rewrite or replace Admin website logic.

Locked Admin URL:
https://mhacdelivery.devs.surf/admin.html

APK build:
- This project includes a GitHub Actions workflow.
- Upload the whole project to a GitHub repository.
- Open Actions -> Build MHAC Admin APK -> Run workflow.
- Download the MHAC-ADMIN-APK artifact.

No changes are required to admin.html.
